# QuantumArt/storage

Хранилище файлов QP: **98 файлов, 1.47 ГБ** — дистрибутивы, базы данных,
руководства и архивы. Заменяет внешний хост `storage.qp.qsupport.ru`, на который
ссылается портал `downloads.quantumart.ru`.

## Как это работает

```
браузер → https://storage.quantumart.ru/downloads/<файл>
        → nginx на VPS (:443) → контейнер storage-web (127.0.0.1:3023)
        → 302 на https://github.com/QuantumArt/storage/releases/download/v1/<файл>
        → GitHub отдаёт байты
```

Сервис сам ничего не хранит: в образе только страница со списком файлов, всё
остальное — редиректы. Почему именно так и почему не LFS и не «просто в git» —
в [`site/README.md`](site/README.md) и [`docs/DEPLOY-SPEC.md`](docs/DEPLOY-SPEC.md) §2.

## Инструменты

| Скрипт | Назначение |
|---|---|
| `tools/fetch_origin.py` | скачать с оригинала кусками с проверкой каждого ответа и сверкой с эталоном |
| `tools/make_vps_script.py` | сгенерировать самодостаточный скрипт загрузки для VPS |
| `tools/fetch_on_vps.sh` | результат генерации: 98 URL внутри, проверка размера и целостности, вывод sha256 |
| `tools/build_migration.py` | маппинг старых ссылок на новые + спека для коллеги |
| `tools/verify.py` | сквозная проверка: файлы, ассеты релиза анонимно, живые ссылки |
| `tools/build_index.py` | страница со списком файлов и `map` имён для nginx |

## Проверка

```bash
python3 tools/verify.py --local     # файлы против эталона + целостность формата
python3 tools/verify.py --release   # ассеты GitHub Release, анонимно
python3 tools/verify.py --live      # живые ссылки storage.quantumart.ru
```

## Три вещи, которые стоит знать, прежде чем что-то менять

1. **Манифест не является доказательством целостности.** `manifest/manifest.json`
   вычислен из того же скачивания, что и файлы, поэтому сверка «файл против
   манифеста» всегда зелёная. Доказательство — `manifest/reference-sha256.txt`,
   собранный независимым проходом на другой машине.
2. **GitHub молча меняет имена ассетов.** `QP_Setup_7.9.7.0..zip` загружается как
   `QP_Setup_7.9.7.0.zip`. Проверено и созданием релиза, и перезаливом.
   Поэтому список имён ассетов генерируется в nginx из манифеста, а неизвестное
   имя отдаёт 404, а не 302 на пустоту.
3. **Оригинал отдаёт крупные файлы по ~120 КБ/с и рвёт соединения.** Отсюда
   кусочная загрузка по 8 МБ с проверкой кода и размера каждого ответа.
